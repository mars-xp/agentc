# AgentC phase notes

This page keeps the phase-by-phase notes that used to sit on the README.
The README is the install and command page.

## What each phase added

Phase 6 adds `--format protocol` for machine-readable stdout: one JSON object (envelope) with six keys — `protocolVersion`, `status`, `summary`, `diagnostics`, `artifacts`, and `confirmation`. Host Skill sources live at `integrations/host-skills/` as one `agent-project`; build and package them with existing adapters (no compiler inside the plugin tree). Phase 5 leftover security and packaging adds read-only `audit --for-public DIR` (Phase 0 scan; both the flag and `DIR` are required) and, after `package` writes each zip, sidecar `<name>.zip.sha256` and `<name>.zip.cdx.json` beside the zip with member timestamps pinned to 1980-01-01 (see ADR 0010). Phase 5 also adds `install` / `install all` / `uninstall` / `status` / `sync` / `restore` for Cursor, Codex, and Claude Code plugin zips: extract to a staging tree, compare with the install destination, and write only with `--yes`. Without `--yes`, nothing is written. With `--yes`, identical destinations succeed without writing; conflicts fail without writing (no `--force`). Install records a sidecar ledger under `--root/.agentc/installs/<host>/` (see ADR 0009). `sync` and `uninstall` snapshot registered files to `--root/.agentc/backups/<host>/<name>/` before replacing or deleting (see ADR 0012). `restore` undoes a successful `sync` or `uninstall`. `status` reads the ledger and reports backup availability; backup-only slots are not treated as installed. `sync` updates unmodified registered files from a zip. Install does not call Adapter `install`. Phase 4 adds read-only `inspect` and confirm-to-write `import` for Cursor plugin trees plus leftover host kinds (`cursor-workspace`, `cursor-user`, `codex`, `claude-code`), sharing one scan → classify → plan pipeline. `import merge` composes two or more of those host trees into one `agent-project`. After merge, Skills / Rules / Commands / Agents that belong to only one host are written as `add-file` operations in `overlays/<host>/import-merge.json` (see ADR 0014). `--from` is required; the CLI does not default to `~/.cursor` or any other home directory. `inspect` accepts optional `--kind`; omit it to auto-detect from mutually exclusive fingerprints. Earlier phases still cover `init`, `create` (skill / rule / command / agent), source-level `validate`, `build` (translation layer → existing host adapters), and `package` (zip existing `build/outputs/` into `build/dist/`). `validate` still does not call `plugin_compiler`; `build` and `package` do.

## ADR summary

Phase 1 `validate` does not call `plugin_compiler`. Phase 2 `build` wraps existing adapters through a translation layer without changing the orchestrator main path (see ADR 0003). Phase 3 `package` only zips existing `build/outputs/` via `zip_plugin_tree`; it does not call `publish_local` or add Adapter SPI `package()` (see ADR 0004). Phase 4 `inspect` and `import cursor` share a translation-layer façade in `src/agentc/importers/` without landing a full Importer SPI (see ADR 0005). Remaining host kinds (`cursor-workspace`, `cursor-user`, `codex`, `claude-code`) stay on that façade with fail-closed fingerprint auto-detect; they are not an Importer SPI (see ADR 0008). Phase 4 leftover `import merge` composes existing ImportPlans without an Importer SPI (see ADR 0011). `--from` remains required and does not default to a home directory. Phase 5 `install` uses a translation-layer façade in `src/agentc/installer/` without calling `CursorAdapter.install()` (see ADR 0006). Remaining Phase 5 install (Codex / Claude Code zip install, uninstall, `status`, `sync`, `restore`) keeps that façade and records a sidecar ledger outside the plugin tree (see ADR 0009). `install all` composes existing single-host `install_zip` in a fixed order without a second write path (see ADR 0013). Pre-write backups live beside the ledger at `--root/.agentc/backups/<host>/<name>/` (see ADR 0012). Remaining Phase 5 security and packaging keeps a translation-layer façade in `src/agentc/audit/` that calls existing Phase 0 `opensource_phase0.scan`; `package` writes sidecar SHA-256 and CycloneDX beside each zip and pins zip member time in `zip_plugin_tree`; it does not change `copy_candidate` public behavior (see ADR 0010). Phase 6 `--format protocol` assembles a CLI stdout envelope in `src/agentc/protocol/` without changing the five-key `--format json` array; host Skills ship from `integrations/host-skills/` via existing adapters (see ADR 0007).
